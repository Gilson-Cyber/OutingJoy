OUTINGJOY — GITHUB UPLOAD GUIDE

Upload all 3 files in this folder to the ROOT of your GitHub repository:

1. index.html
2. README.md
3. GITHUB_UPLOAD_INSTRUCTIONS.txt

Then in GitHub:
Settings → Pages → Build and deployment
Source: Deploy from a branch
Branch: main
Folder: /(root)
Click Save.

Important:
- index.html is the actual OutingJoy website.
- README.md documents the project.
- GITHUB_UPLOAD_INSTRUCTIONS.txt is only this setup guide and does not affect the website.
- No API key or backend is required for this version.
